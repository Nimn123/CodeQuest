# CODE QUEST — AI Bug Hunt

A small browser quiz for a live AI-assisted debugging demonstration.

## Run it
1. Clone or download this repository.
2. Open `index.html` in a modern browser.
3. Answer questions and try restarting.

No build tools, packages, API keys, or internet connection are required.

## Mission
Use an AI coding agent to inspect the app, reproduce its bugs, explain root causes, make focused fixes, and test the result.

Ask the agent to:
1. Identify the bugs and explain how to reproduce each one.
2. Propose the smallest safe fixes.
3. Apply the changes.
4. Explain the changed code.
5. Provide a manual test checklist.

Do not ask it to rewrite the entire app.

## Challenge questions
- Can the score exceed the number of questions?
- Does restarting truly start a new game?
- What other edge cases should be tested before publishing?

This starter intentionally contains bugs. It is for teaching, not production use.
